# Notes for slice C4 (ADR-0078, domain controller checks), for the integrator

## Changelog lines

- Compliance checks (ADR-0078 C4): 21 read-only checks for domain controllers in a new hardening module (`dc`): LDAP signing and channel
  binding, Kerberos encryption types and RC4, `krbtgt` password age, DSRM logon, the domain password and lockout policy, who is in the
  privileged groups (counts), stale accounts and passwords that never expire (counts), the time hierarchy, replication, SYSVOL and the
  directory backup. They apply to domain controllers only, are mapped to NIST SP 800-171 and CMMC requirements, and sit in a new
  "domain controller" profile. None has a fix.
