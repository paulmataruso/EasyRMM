# ADR-0055 slice 5b4: DNS-01 challenge support

Branch `integration/2026-11`, based on the integration branch.

## Built

* **`server/internal/tlsdns`** (new): DNS-01 challenge credential manager.
  * Providers: RFC 2136 (BIND, Knot, PowerDNS with TSIG HMAC-SHA256/384/512)
    and Cloudflare (API token). HMAC-MD5 and HMAC-SHA1 are refused.
  * `Save`: validates, normalises the zone, seals credentials with the row UUID
    as associated data, tests by creating and removing a TXT record, persists.
    Duplicate zones return `ErrDuplicateZone`.
  * `Replace`: updates an existing credential in place with the same test.
  * `Remove`: deletes a credential row.
  * `Retest`: re-runs the TXT create/remove test on an existing credential.
  * `SolverFor(ctx, name)`: walks the domain labels to find zone credentials,
    builds a `certmagic.DNS01Solver` with Resolvers and OverrideDomain.
  * `List`: returns credentials without secrets.
  * Cloud metadata blocking: 169.254.169.254 and fd00:ec2::254 are refused as
    RFC 2136 server addresses.
  * Error classification: library errors mapped to fixed reasons (refused,
    timed_out, not_authorized, zone_not_found, unknown).
  * Audit actions: `tls.dns_save`, `tls.dns_replace`, `tls.dns_remove`,
    `tls.dns_test`.

* **`server/internal/tlscert/dnssolver.go`** (new): `dnsSolverMux` dispatches
  DNS-01 challenges to per-zone solvers looked up at challenge time. Implements
  `acmez.Solver` and `acmez.Waiter`. CertMagic's ACME issuer calls it; it
  looks up the right DNS provider for each name via `SolverFor` and delegates
  `Present`, `Wait`, `CleanUp`.

* **`server/internal/httpapi/tlsdnsapi`** (new): HTTP routes, all behind
  `settings.manage`; writes require step-up authentication.
  * `GET  /api/v1/settings/certificates/dns` — list
  * `POST /api/v1/settings/certificates/dns` — save (step-up)
  * `PUT  /api/v1/settings/certificates/dns/{id}` — replace (step-up)
  * `DELETE /api/v1/settings/certificates/dns/{id}` — remove (step-up)
  * `POST /api/v1/settings/certificates/dns/{id}/test` — retest

* **Migration** `00094_tls_dns_credentials.sql`: credentials table with sealed
  credentials column, unique zone index.

* **Console**: `DNSProviders` component on Settings > Certificates: add/remove
  providers, test on save, re-test button, delegation guidance.

* **Wiring**: `tlsdns.Service` created in `app.go`, its `SolverFor` passed as
  the `DNSSolver` callback to `tlscert.Settings`; `tlsdnsapi` routes registered.
