# Notes for the integrator: slice C1 (ADR-0078, the library, packs and scan)

## Changelog lines

- Compliance engine, first slice (ADR-0078): a control library of 234 independently written controls (every Windows and Linux hardening setting),
  13 framework packs (NIST SP 800-171 r2 with full text, CMMC levels 1 and 2, NIST SP 800-53 r5 view, NIST CSF 2.0, HIPAA technical safeguards,
  DISA STIG ids, GDPR and SOC 2 indicative, a CIS cross-reference by number only), licence and provenance metadata on every item, and
  `packlint`, the build check that keeps restricted content out of a commercial build.
- Compliance scans read per-control results from the hardening checks (read-only, no fixes yet), with a roll-up per requirement that never says
  "compliant": a requirement is "checked: all in-scope computers meet", "checked: does not meet" or "not assessed".

## Privacy notes

- Per-control results record a computer's configuration (settings values) per organization, behind row-level security and
  `compliance.view` (Read-Only holds none). Results history is kept (retention setting default 6 years, pending owner confirmation) and the
  audit log records `compliance.scan_start` and `compliance.settings_update`. No personal data is added.
